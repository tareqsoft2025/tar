# مواقيت الصلاة (تطبيق أندرويد)

تطبيق مبني بـ Capacitor (HTML/JS) يعرض: مواقيت الصلاة (حساب محلي بدون إنترنت)، العد التنازلي للصلاة القادمة، التاريخ الهجري، اتجاه القبلة بالبوصلة، مسبحة إلكترونية، وتنبيهات عند دخول الوقت.

## الحصول على ملف APK
1. ادفع الكود إلى GitHub (يتم البناء تلقائياً) أو شغّل **Actions → Build Android APK → Run workflow**.
2. بعد انتهاء العمل، نزّل `prayer-app-apk` من قسم **Artifacts** وفك الضغط ثم ثبّت `app-debug.apk` على الجوال (فعّل "التثبيت من مصادر غير معروفة").

## البناء محلياً
يتطلب Node 20 و JDK 17 و Android SDK:
```
npm ci
npx cap add android && npx cap sync android
cd android && ./gradlew assembleDebug
```
الملف الناتج: `android/app/build/outputs/apk/debug/app-debug.apk`

## بناء APK بدون Android SDK
```
bash native/build.sh      # الناتج: native/build/prayer.apk (نسخة جاهزة في dist/prayer.apk)
```
يستخدم WebView أصلي (Java) مع نفس واجهة `www/`. التوقيع بمفتاح تجريبي (`native/debug.p12`) ويتطلب أندرويد 7.0 فأعلى.

## التحديث الإجباري التلقائي
**وصول التحديث مباشرة:** التطبيق المثبّت يفحص وجود نسخة جديدة كل ساعة في الخلفية (وبعد إعادة تشغيل الجوال، وكل 10 دقائق أثناء فتحه)، فينزّل الـ APK مسبقاً ويرسل إشعار "تحديث جديد جاهز"؛ الضغط عليه يفتح نافذة التثبيت فوراً. (أندرويد يشترط دائماً ضغطة "تثبيت" من المستخدم للتطبيقات المثبّتة من خارج المتجر.)

**إصدار تلقائي:** عند كل دمج في `main` يغيّر `www/` أو `native/` يعمل `Auto release (forced update)` في GitHub Actions: يرفع رقم النسخة (مثلاً 5.7 ← 5.8)، يبني الـ APK ويحدّث `dist/version.json` بملاحظات مأخوذة من عنوان الدمج، فيصل التحديث الإجباري لكل المستخدمين دون أي خطوة يدوية. إذا كان الدمج قد رفع النسخة يدوياً يتخطّى الإصدار التلقائي. يمكن تشغيله يدوياً من Actions مع كتابة ملاحظات.

الطريقة اليدوية (اختيارية):
عند كل فتح للتطبيق يقرأ `dist/version.json` من فرع `main`؛ إذا كان `versionCode` فيه أحدث من المثبّت تظهر شاشة تحديث لا يمكن تجاوزها، تنزّل `dist/prayer.apk` وتفتح نافذة التثبيت.
لإصدار نسخة جديدة بعد أي تعديل:
```
./native/release.sh 1.3 "ملاحظات التحديث"
git add -A && git commit -m "release 1.3" && git push   # ثم ادمج في main
```

## تطبيق ويب قابل للإضافة (PWA)
مجلد `docs/` نسخة ويب كاملة من التطبيق (تعمل دون إنترنت بعد أول فتح). فعّل **Settings → Pages → Deploy from a branch → main / docs**، ثم افتح الرابط في Chrome واختر "إضافة إلى الشاشة الرئيسية" لتثبيته كتطبيق مصغّر.

## الودجت والشاشة الرئيسية
- **ودجت الصلاة** (الصلاة القادمة + عدّ تنازلي مباشر + أوقات اليوم): من الإعدادات ← الشاشة الرئيسية ← "إضافة ودجت الصلاة"، أو من الشاشة الرئيسية: ضغط مطوّل ← الودجات ← مواقيت الصلاة.
- **اختصار التطبيق** على الشاشة الرئيسية من نفس القسم.
- بناء الـ APK يحتاج الآن `aapt` و`zipalign`: `apt-get install -y aapt zipalign`.

## الميزات الإضافية (v3.0)
- **قضاء الصلوات:** عدّاد للفوائت.
- **القرآن الكريم:** مصحف مدمج بلا إنترنت، علامات مرجعية، آخر موضع قراءة، ورد يومي، وتلاوة صوتية (تحتاج إنترنت). المصدر: quranenc.com عبر quran-json (CC BY-SA 4.0).
- **الأذكار:** صباح، مساء، بعد الصلاة، النوم + تذكير تلقائي بها.
- **التقويم الهجري:** شهر كامل مع الأيام البيض والمناسبات وتذكير بصيام الاثنين والخميس.
- **أقرب المساجد:** بحث في OpenStreetMap (يحتاج إنترنت).

- **مواقف وعِبر:** 17 موقفاً من حياة النبي ﷺ مع الموعظة والمصدر، وموقف لكل يوم.
- **أحاديث نبوية:** 49 حديثاً بالتخريج والفائدة مع بحث وتصنيف ومفضلة ومشاركة، وحديث اليوم في الشاشة الرئيسية.
- **أحداث التقويم الهجري:** ذكريات تاريخية (بدر، فتح مكة، عين جالوت، حطين، تحرير القدس...) تظهر في التقويم.
- **الحالة الجوية:** درجة الحرارة والحالة والعظمى والصغرى حسب موقعك (Open-Meteo، تُحفظ آخر نتيجة للعمل دون اتصال).
- **الدولار والشيكل:** سعر الصرف الحي في الرئيسية ومحوّل ثنائي الاتجاه (Open Exchange Rates مع Frankfurter احتياطاً).
- **وضع المسجد:** صمت تلقائي بعد الأذان بدقيقتين ولمدة تختارها ثم يعود وضع الجوال السابق (يحتاج إذن "عدم الإزعاج").
- **صوت الأذان:** اختيار نغمة الجهاز لإشعار الأذان ولإشعار الفجر.
- **أسماء الله الحسنى:** 99 اسماً بمعانيها، اسم اليوم في الرئيسية، واختبار قصير.
- **أدعية مأثورة:** 29 دعاءً مصنفة حسب الموقف مع العزو والبحث.
- **ختمة القرآن:** خطة 30/60/90/180 يوماً وهدف يومي وتقدّم مرتبط بالقارئ.
- المحتوى في `www/content.js` وقابل للتوسعة.

## الموارد البشرية (v6.0)
ربط التطبيق بنظام المؤسسة **PEF ERP** (`www.pef-erp-system.org`) للقراءة فقط:
- **الدخول** برقم الهوية وكلمة المرور عبر الطبقة الأصلية (`ErpClient.java`)؛ كلمة المرور لا تُحفظ، والجلسة في كوكيز داخل التطبيق.
- **مزامنة تراكمية** (`www/hr-data.js`): الموظفون والعقود والتكليفات تُدمج بالمعرّف (جديد/محدّث/محذوف فقط)، والحضور يُجلب للأيام غير المزامنة + اليوم وأمس، والإجازات/المهام من `leave-map`.
- **التخزين على الجوال** في ملفات خاصة بالتطبيق (`files/hr/`)، ويعمل دون إنترنت.
- **الشاشات** (`www/hr.js`): لوحة اليوم، الحضور بفلاتر PEF/HHO ومكتبي/ميداني والحالة (متأخر، بلا تسجيل ولا إجازة، بلا دخول، بلا تكليف) مع مشاركة القائمة، الموظفون وملف الموظف، العقود (عقد/تمديد/ملحق/تسكين/تعديل) وما ينتهي قريباً، التكليفات حسب المشروع.
- حساب التأخير مثل النظام: أول تسجيل دخول بعد بداية الدوام (مكتبي/ميداني) + فترة السماح، قابلة للتعديل من إعدادات القسم.

## الخريطة دون إنترنت (v7.0)
- ملف `dist/maps/gaza.pmtiles` (نحو 11 م.ب): بلاطات متجهة لقطاع غزة من بيانات OpenStreetMap عبر Protomaps (رخصة ODbL)، حتى مستوى تكبير 15 مع تكبير إضافي سلس.
- يُنزَّل تلقائياً مرة واحدة عند توفر الإنترنت (من إعدادات الموارد البشرية: تنزيل/حذف/تنزيل تلقائي) إلى ملفات التطبيق (`OfflineMap.java`)، وتقرأ الصفحة منه أجزاء صغيرة عبر الجسر (`mapRead`) وتُرسم بـ `protomaps-leaflet`.
- في خريطة الحضور: داخل غزة تُستخدم الخريطة المحلية (أسماء شوارع عربية) بدون إنترنت؛ خارجها تُعرض خرائط Esri عبر الإنترنت، وإن انقطع الإنترنت تتحول تلقائياً إلى المحلية.
- لإضافة منطقة أخرى (مثل الضفة): `python3 native/tools/extract_map.py --bbox غرب,جنوب,شرق,شمال --maxzoom 15 --out dist/maps/اسم.pmtiles` (يتطلب `pip install pmtiles`).

## الرسائل والقوالب (v7.1)
- **الرسائل القصيرة**: تُفتح عبر `ACTION_SENDTO` مع `smsto:` ونص جاهز (`MainActivity.composeSms`)، والرقم يُستخدم كما هو في النظام؛ إن كُتب بلا صفر (`598815128`) يُضاف `0` فيصير `0598815128`، والدولي (`+970…`) يبقى كما هو.
- **قوالب جاهزة** قابلة للتعديل والحفظ: "إنهاء العقد"، "انتهاء التكليف"، "رسالة حرة"، وقوالب جديدة باسمك. المتغيرات: `{الاسم} {اليوم} {التاريخ} {نهاية_العقد} {نهاية_التكليف} {المشروع} {المسمى} {رقم_العقد}`، وتُملأ لكل موظف من بيانات عقده أو تكليفه.
- **تحديد أكثر من موظف** (زر "تحديد" في الحضور وساعات الأسبوع والإجازات والموظفين والعقود والتكليفات) ثم "رسالة": معاينة، اختيار SMS أو واتساب، وقائمة إرسال تفتح الرسائل واحدة تلو الأخرى بنص مخصص. وأزرار "إرسال إشعار" سريعة داخل نافذة العقد والتكليف والموظف.

## إشعارات الحضور المنبثقة (v7.2)
- عند كل مزامنة تُكتشف تسجيلات حضور/انصراف **جديدة** (اليوم وأمس فقط، ولا تنبيه في أول مزامنة) فتظهر **نافذة في منتصف الشاشة**: اسم الموظف ووقت التسجيل وفي الموعد/متأخر وداخل/خارج موقع العمل والمسافة (أو عدّاد وقائمة عند وصول عدة تسجيلات)، وتُغلق تلقائياً بعد 14–20 ثانية.
- تظهر في أي شاشة من التطبيق (المزامنة التلقائية تعمل الآن من أي شاشة، ويمكن جعلها كل 5 دقائق)، وعند المزامنة في الخلفية (`HrSyncJob`) تظهر **فوق التطبيقات** (بإذن العرض فوق التطبيقات) أو كإشعار عاجل (`ReminderActivity.fireAtt`).
- التحكم من الموارد البشرية ← الإعدادات ← "إشعارات الحضور المنبثقة": كل التسجيلات / الحضور فقط / المتأخرون والخارجون عن الموقع / إيقاف، وزر "تجربة النافذة".

## المتابعة في الخلفية والإنترنت الضعيف (v7.3)
- **متابعة الحضور والتطبيق مغلق**: خدمة أمامية خفيفة (`HrWatchService`) تفحص تسجيلات اليوم الجديدة كل 1–15 دقيقة (من الإعدادات)، وتعرض نافذة منتصف الشاشة فوق التطبيقات. تُستأنف تلقائياً بعد إعادة تشغيل الهاتف أو تحديث التطبيق. يُنصح باستثناء التطبيق من توفير البطارية ومنح إذن الظهور فوق التطبيقات.
- **كفاءة على 2G**: أوضاع مزامنة (سريعة = طلب واحد صغير لحضور اليوم تراكمياً، خفيفة، كاملة)، البيانات الكبيرة كل 6 ساعات فقط (12 على الاتصال الضعيف)، صفحات أصغر، إعادة محاولة تلقائية مع تأخير تصاعدي، مهلات أطول، وحفظ كل قسم فور اكتماله فلا يضيع التقدم عند الانقطاع.
- **تنزيل الخريطة قابل للاستكمال** (Range/ETag) وتلقائياً على Wi‑Fi فقط.
