# مواقيت الصلاة (تطبيق أندرويد)

تطبيق مبني بـ Capacitor (HTML/JS) يعرض: مواقيت الصلاة (حساب محلي بدون إنترنت)، العد التنازلي للصلاة القادمة، التاريخ الهجري، اتجاه القبلة بالبوصلة، مسبحة إلكترونية، وتنبيهات عند دخول الوقت.

## الحصول على ملف APK
1. ادفع الكود إلى GitHub (يتم البناء تلقائياً) أو شغّل **Actions → Build Android APK → Run workflow**.
2. بعد انتهاء العمل، نزّل `prayer-app-apk` من قسم **Artifacts** وفك الضغط ثم ثبّت `app-debug.apk` على الجوال (فعّل "التثبيت من مصادر غير معروفة").

## البناء محلياً
يتطلب Node 20 و JDK 17 و Android SDK:
```
npm ci
npx cap add android && npx cap sync android
cd android && ./gradlew assembleDebug
```
الملف الناتج: `android/app/build/outputs/apk/debug/app-debug.apk`

## بناء APK بدون Android SDK
```
bash native/build.sh      # الناتج: native/build/prayer.apk (نسخة جاهزة في dist/prayer.apk)
```
يستخدم WebView أصلي (Java) مع نفس واجهة `www/`. التوقيع بمفتاح تجريبي (`native/debug.p12`) ويتطلب أندرويد 7.0 فأعلى.

## التحديث الإجباري التلقائي
**وصول التحديث مباشرة:** التطبيق المثبّت يفحص وجود نسخة جديدة كل ساعة في الخلفية (وبعد إعادة تشغيل الجوال، وكل 10 دقائق أثناء فتحه)، فينزّل الـ APK مسبقاً ويرسل إشعار "تحديث جديد جاهز"؛ الضغط عليه يفتح نافذة التثبيت فوراً. (أندرويد يشترط دائماً ضغطة "تثبيت" من المستخدم للتطبيقات المثبّتة من خارج المتجر.)

**إصدار تلقائي:** عند كل دمج في `main` يغيّر `www/` أو `native/` يعمل `Auto release (forced update)` في GitHub Actions: يرفع رقم النسخة (مثلاً 5.7 ← 5.8)، يبني الـ APK ويحدّث `dist/version.json` بملاحظات مأخوذة من عنوان الدمج، فيصل التحديث الإجباري لكل المستخدمين دون أي خطوة يدوية. إذا كان الدمج قد رفع النسخة يدوياً يتخطّى الإصدار التلقائي. يمكن تشغيله يدوياً من Actions مع كتابة ملاحظات.

الطريقة اليدوية (اختيارية):
عند كل فتح للتطبيق يقرأ `dist/version.json` من فرع `main`؛ إذا كان `versionCode` فيه أحدث من المثبّت تظهر شاشة تحديث لا يمكن تجاوزها، تنزّل `dist/prayer.apk` وتفتح نافذة التثبيت.
لإصدار نسخة جديدة بعد أي تعديل:
```
./native/release.sh 1.3 "ملاحظات التحديث"
git add -A && git commit -m "release 1.3" && git push   # ثم ادمج في main
```

## تطبيق ويب قابل للإضافة (PWA)
مجلد `docs/` نسخة ويب كاملة من التطبيق (تعمل دون إنترنت بعد أول فتح). فعّل **Settings → Pages → Deploy from a branch → main / docs**، ثم افتح الرابط في Chrome واختر "إضافة إلى الشاشة الرئيسية" لتثبيته كتطبيق مصغّر.

## الودجت والشاشة الرئيسية
- **ودجت الصلاة** (الصلاة القادمة + عدّ تنازلي مباشر + أوقات اليوم): من الإعدادات ← الشاشة الرئيسية ← "إضافة ودجت الصلاة"، أو من الشاشة الرئيسية: ضغط مطوّل ← الودجات ← مواقيت الصلاة.
- **اختصار التطبيق** على الشاشة الرئيسية من نفس القسم.
- بناء الـ APK يحتاج الآن `aapt` و`zipalign`: `apt-get install -y aapt zipalign`.

- **ختمة القرآن:** خطة 30/60/90/180 يوماً وهدف يومي وتقدّم مرتبط بالقارئ.

## الموارد البشرية (v6.0)
ربط التطبيق بنظام المؤسسة **PEF ERP** (`www.pef-erp-system.org`) للقراءة فقط:
- **الدخول** برقم الهوية وكلمة المرور عبر الطبقة الأصلية (`ErpClient.java`)؛ كلمة المرور لا تُحفظ، والجلسة في كوكيز داخل التطبيق.
- **مزامنة تراكمية** (`www/hr-data.js`): الموظفون والعقود والتكليفات تُدمج بالمعرّف (جديد/محدّث/محذوف فقط)، والحضور يُجلب للأيام غير المزامنة + اليوم وأمس، والإجازات/المهام من `leave-map`.
- **التخزين على الجوال** في ملفات خاصة بالتطبيق (`files/hr/`)، ويعمل دون إنترنت.
- **الشاشات** (`www/hr.js`): لوحة اليوم، الحضور بفلاتر PEF/HHO ومكتبي/ميداني والحالة (متأخر، بلا تسجيل ولا إجازة، بلا دخول، بلا تكليف) مع مشاركة القائمة، الموظفون وملف الموظف، العقود (عقد/تمديد/ملحق/تسكين/تعديل) وما ينتهي قريباً، التكليفات حسب المشروع.
- حساب التأخير مثل النظام: أول تسجيل دخول بعد بداية الدوام (مكتبي/ميداني) + فترة السماح، قابلة للتعديل من إعدادات القسم.

## الخريطة دون إنترنت (v7.0)
- ملف `dist/maps/gaza.pmtiles` (نحو 11 م.ب): بلاطات متجهة لقطاع غزة من بيانات OpenStreetMap عبر Protomaps (رخصة ODbL)، حتى مستوى تكبير 15 مع تكبير إضافي سلس.
- يُنزَّل تلقائياً مرة واحدة عند توفر الإنترنت (من إعدادات الموارد البشرية: تنزيل/حذف/تنزيل تلقائي) إلى ملفات التطبيق (`OfflineMap.java`)، وتقرأ الصفحة منه أجزاء صغيرة عبر الجسر (`mapRead`) وتُرسم بـ `protomaps-leaflet`.
- في خريطة الحضور: داخل غزة تُستخدم الخريطة المحلية (أسماء شوارع عربية) بدون إنترنت؛ خارجها تُعرض خرائط Esri عبر الإنترنت، وإن انقطع الإنترنت تتحول تلقائياً إلى المحلية.
- لإضافة منطقة أخرى (مثل الضفة): `python3 native/tools/extract_map.py --bbox غرب,جنوب,شرق,شمال --maxzoom 15 --out dist/maps/اسم.pmtiles` (يتطلب `pip install pmtiles`).

## الرسائل والقوالب (v7.1)
- **الرسائل القصيرة**: تُفتح عبر `ACTION_SENDTO` مع `smsto:` ونص جاهز (`MainActivity.composeSms`)، والرقم يُستخدم كما هو في النظام؛ إن كُتب بلا صفر (`598815128`) يُضاف `0` فيصير `0598815128`، والدولي (`+970…`) يبقى كما هو.
- **قوالب جاهزة** قابلة للتعديل والحفظ: "إنهاء العقد"، "انتهاء التكليف"، "رسالة حرة"، وقوالب جديدة باسمك. المتغيرات: `{الاسم} {اليوم} {التاريخ} {نهاية_العقد} {نهاية_التكليف} {المشروع} {المسمى} {رقم_العقد}`، وتُملأ لكل موظف من بيانات عقده أو تكليفه.
- **تحديد أكثر من موظف** (زر "تحديد" في الحضور وساعات الأسبوع والإجازات والموظفين والعقود والتكليفات) ثم "رسالة": معاينة، اختيار SMS أو واتساب، وقائمة إرسال تفتح الرسائل واحدة تلو الأخرى بنص مخصص. وأزرار "إرسال إشعار" سريعة داخل نافذة العقد والتكليف والموظف.

## إشعارات الحضور المنبثقة (v7.2)
- عند كل مزامنة تُكتشف تسجيلات حضور/انصراف **جديدة** (اليوم وأمس فقط، ولا تنبيه في أول مزامنة) فتظهر **نافذة في منتصف الشاشة**: اسم الموظف ووقت التسجيل وفي الموعد/متأخر وداخل/خارج موقع العمل والمسافة (أو عدّاد وقائمة عند وصول عدة تسجيلات)، وتُغلق تلقائياً بعد 14–20 ثانية.
- تظهر في أي شاشة من التطبيق (المزامنة التلقائية تعمل الآن من أي شاشة، ويمكن جعلها كل 5 دقائق)، وعند المزامنة في الخلفية (`HrSyncJob`) تظهر **فوق التطبيقات** (بإذن العرض فوق التطبيقات) أو كإشعار عاجل (`ReminderActivity.fireAtt`).
- التحكم من الموارد البشرية ← الإعدادات ← "إشعارات الحضور المنبثقة": كل التسجيلات / الحضور فقط / المتأخرون والخارجون عن الموقع / إيقاف، وزر "تجربة النافذة".

## المتابعة في الخلفية والإنترنت الضعيف (v7.3)
- **متابعة الحضور والتطبيق مغلق**: خدمة أمامية خفيفة (`HrWatchService`) تفحص تسجيلات اليوم الجديدة كل 1–15 دقيقة (من الإعدادات)، وتعرض نافذة منتصف الشاشة فوق التطبيقات. تُستأنف تلقائياً بعد إعادة تشغيل الهاتف أو تحديث التطبيق. يُنصح باستثناء التطبيق من توفير البطارية ومنح إذن الظهور فوق التطبيقات.
- **كفاءة على 2G**: أوضاع مزامنة (سريعة = طلب واحد صغير لحضور اليوم تراكمياً، خفيفة، كاملة)، البيانات الكبيرة كل 6 ساعات فقط (12 على الاتصال الضعيف)، صفحات أصغر، إعادة محاولة تلقائية مع تأخير تصاعدي، مهلات أطول، وحفظ كل قسم فور اكتماله فلا يضيع التقدم عند الانقطاع.
- **تنزيل الخريطة قابل للاستكمال** (Range/ETag) وتلقائياً على Wi‑Fi فقط.

## تصميم الموارد البشرية الجديد (v8.0)

## الموافقة على الطلبات من التطبيق (v8.1)
- ضغط أي طلب في قسم "الطلبات" يفتح تفاصيله مع رصيد الموظف؛ وللطلبات المعلّقة أزرار موافقة/رفض بتأكيد من خطوتين (والرفض مع سبب اختياري).
- نفس خطوات نظام PEF: الإجازة اليومية (مُرسل ← موافقة المدير ← اعتماد)، والمغادرة الساعية ومهمة العمل (مُرسل ← اعتماد/رفض). العمل الإضافي والعمل في العطل يبقى من النظام.
- القرار يُرسل عبر الطبقة الأصلية (PUT على مسارات الطلبات فقط) باسم حسابك، وصلاحيات النظام هي المرجع؛ تظهر رسالة واضحة عند الرفض بسبب الصلاحية أو الانقطاع، ولا يُعاد إرسال الطلب تلقائياً.

## واتساب: تبديل تلقائي بين +970 و+972 (v8.18)
- واتساب لا يخبر التطبيقات هل الرقم مسجّل، فعند العودة من واتساب يسأل التطبيق سؤالاً واحداً: «هل فُتحت المحادثة؟». «نعم» تحفظ المقدمة الصحيحة لهذا الموظف لتكون الأولى دائماً. «لا — جرّب +972/+970» تفتح الرقم الآخر **تلقائياً** بالرسالة نفسها. وإن لم يُسجَّل الرقمان على واتساب يُعلَّم الموظف «بلا واتساب» ويظهر زر «SMS بدلاً».
- يسري ذلك على كل مواضع واتساب: قائمة الإرسال الجماعي، ملف الموظف، ونافذة ملف PEF في النظام المساعد.
- لا يُعدّ المستلم منجزاً في القائمة إلا بعد تأكيد وصول المحادثة.

## 8.21 — تقرير أسبوعي، مجموعات ذكية، إنذارات رسمية، وتعديل الحضور
- **التقرير الأسبوعي:** «المزيد ← التقرير الأسبوعي للمدير»: صورة منسّقة (نسبة الحضور، تأخر، بلا تسجيل، إجازات، أعمدة يومية، الأكثر تأخراً/غياباً، أعلى المواقع) تُشارك عبر واتساب أو كنص. تحترم المجموعة المختارة. يُحسب محلياً بلا طلبات للنظام. (`www/hr-report.js` + `ShareProvider` + جسر `shareImage`.)
- **المجموعات الذكية (⚡):** قاعدة بشروط (القسم/المسمى/المدير/الجهة/نوع الدوام/انتهاء العقد أو التكليف خلال N يوم) بمنطق «كل الشروط» أو «أي شرط»؛ الأعضاء يتحدّثون تلقائياً.
- **الإنذارات الرسمية:** قوالب إنذار أول/ثانٍ/ثالث ونهائي مع سبب إلزامي، تُسجَّل عند بدء الإرسال في «سجل الإنذارات»، وتظهر عند المستلم الإنذارات السابقة.
- **تعديل الحضور (حساس):** من تفاصيل يوم الموظف: «إضافة تسجيل يدوي» و«تعديل / إخفاء» لكل حدث. تأكيد من خطوتين وسبب إلزامي للتعديل، وسجل تدقيق محلي، ومفتاح تشغيل في الإعدادات. المسارات (مستخرجة من واجهة PEF نفسها، لم تُجرَّب على النظام الحقيقي): `POST /api/hr/attendance/events` (مع `force` عند `invalid_transition`) و`POST /api/hr/attendance/events/{id}/correct` (`action: edit|hide`). مسموح بهما فقط في `ErpClient.write` وبمحاولة واحدة بلا إعادة تلقائية.

## 8.22 — المراجعة الشهرية السرية
- «المزيد ← المراجعة الشهرية السرية»: محمية برمز اختياري (٤–٦ أرقام، يُحفظ مجزّأً SHA-256 على الجهاز) وتُقفل تلقائياً بعد ٣ دقائق أو عند مغادرتها.
- تجمع الشهر لكل موظف: أيام بلا تسجيل ولا إجازة، التأخر (مرات ودقائق)، ساعات العمل، المغادرات الشخصية (طلبات ساعية)، مهام العمل، العمل في عطلة (تسجيل في يوم عطلة أو طلب عمل بعطلة)، وأيام بلا تسجيل خروج.
- الأولوية بحسب الخطورة، وفلاتر «تحتاج قراراً/غياب/تأخر/مغادرات/مهام/عمل بعطلة»، وشريط ألوان للشهر، وجملة قرار سريعة لكل موظف، وأزرار رسالة تأخر/غياب وإنذار (بسبب معبّأ تلقائياً ودرجة تالية)، ومشاركة ملخص الشهر.
- تحترم فلاتر المجموعة والجهة ونوع الدوام، وتُحسب محلياً من `www/hr-review.js` بلا طلبات للنظام.

## 8.23 — عطلة الجمعة والسبت

## 8.24 — الوضع المباشر
- منصة PEF لا توفّر قناة دفع (لا webhook ولا SSE ولا WebSocket في واجهتها)، فالتحديث الفوري الحقيقي من جهتها غير ممكن دون تعديل في خادمها.
- البديل: «الوضع المباشر» يجلب حضور اليوم تراكمياً (طلب واحد صغير) كل ~20 ث وقت الحضور والانصراف، وكل دقيقة بقية الدوام، وكل ٣ دقائق ليلاً/عطلة، ×3 على الشبكة الضعيفة مع تراجع عند الفشل، وفقط والشاشة ظاهرة. يظهر مؤشر «● مباشر · قبل X ث»، ويُعاد الرسم تلقائياً بلا مقاطعة الكتابة، وتظهر نافذة التسجيل الجديد. مفتاح تشغيل في الإعدادات.
- في الخلفية (التطبيق مغلق) تبقى مراقبة 2 دقيقة وقت الحضور.

- بطاقة التوجيه: شارة «مكلَّف: فلان · الحالة · الموعد» إن كُلِّف، وإلا زر «كلّف» (يختار عضواً وموعداً وملاحظة).
- السلة: تبويبان «مهامّي» و«ما كلّفتُ به» (حالة كل مهمة وسجلها وتعليق للمنفّذ وإلغاء التكليف)، وزر «تكليف بمهمة» لمهمة حرّة.

## 8.31 — تفاصيل الراتب في العقد
- في نافذة أي عقد قسم «تفاصيل الراتب» من `GET /api/hr/contracts/{id}/salary-history` (المسار نفسه الذي تستعمله واجهة PEF): الراتب الأساسي الحالي بالتفصيل (الدرجة/الفئة/الخطوة ومنذ متى)، ثم سجل كامل للتغييرات (تعاقد، زيادة سنوية، ترقية، تعديل…) بالراتب والفرق عن السابق (مبلغاً ونسبة) والحالة (معتمد/ملغى) ورقم السجل أو الملحق والسبب، مع البيانات الخام لكل سجل.
- يُحفظ آخر ما جُلب للعرض دون إنترنت. ملاحظة: أسماء حقول السجل مستنتجة من واجهة PEF (`basicSalary`, `currency`, `changeType`, `effectiveFrom`…) ولم تُجرَّب على النظام الحقيقي، والبيانات الخام تظهر لكل سجل للتحقق.

## 8.32 — صورة حالة الدوام اليومية
- أيقونة «صورة اليوم» في أعلى الصفحة الرئيسية (وزر «صورة» في الحضور) تفتح صورة إنفوجرافيك لأي يوم: دائرة نسبة الحضور، حاضر/متأخر/إجازة/مهام/بلا تسجيل/دوام في عطلة، توزيع الحضور حسب السلم (سلم العقد الحالي، وإلا الجهة)، المتأخرون بالدقائق، ومن بلا تسجيل ولا مهام ولا إجازة، وتاريخ اليوم و«بيانات حتى» وقت آخر مزامنة.
- مشاركة كصورة أو نص، وتنقّل بين الأيام، وتحترم المجموعة والجهة ونوع الدوام (`HRReport.daily/dailyCanvas`).
- «بلا تسجيل» = لا تسجيل دوام ولا إجازة يومية ولا أي طلب (مغادرة/مهمة/عمل إضافي) في ذلك اليوم.

## 8.33 — كشفا PEF وHHO + استثناء الأسماء
- في «صور حالة الدوام» تبويبات: ملخص / كشف PEF / كشف HHO. كل كشف صورة بكل الأسماء: الحضور (الوقت دخولاً وخروجاً والموقع)، الإجازات (نوعها)، مهام العمل والمغادرات (الوقت والمشروع/السبب)، بلا تسجيل (لا إجازة ولا مهمة ولا حضور)، وكشف المتأخرين حسب إعدادات الدوام والسماح.
- «مشاركة صورتي PEF و HHO معاً» (جسر `shareImages` ← `ACTION_SEND_MULTIPLE`).
- «استثناء أسماء» (من نافذة الصور ومن المزيد): لا تظهر في صور اليومي والتفصيلي والأسبوعي ولا تُحسب في أرقامها (`repExcl`، `HRReport.detail/detailCanvas`).

## 8.34 — كشوف PEF وHHO بصفحات عالية الجودة
- الكشف التفصيلي صار يُقسَّم تلقائياً إلى صفحات (صور) بحجم ثابت 1080×1620 تُرسم بدقة 1440×2160، بدل صورة واحدة طويلة غير مقروءة. الأقسام تتابع بين الصفحات بعنوان «تابع»، والأقسام الصغيرة لا تُقطَّع، وكل صفحة برأس وتذييل ورقم «صفحة n من N».
- الحضور والمهام بسطرين لكل موظف (الاسم كاملاً ثم الموقع/التفاصيل) فلا تُقتطع الأسماء الطويلة؛ و«بلا تسجيل» بعمودين.
- المشاركة ترسل كل الصفحات معاً (`ACTION_SEND_MULTIPLE`)، ومعاينتها متتابعة داخل التطبيق (`HRReport.detailPages`).

## 8.35 — ملف PDF للكشوف
- زر «ملف PDF لهذا الكشف» و«PDF واحد لـ PEF و HHO» في نافذة الصور: صفحات A4 (595×842) مهيأة للطباعة بخلفية بيضاء، تُنشأ على الجهاز بلا إنترنت (`HRReport.pdfOf`: كل صفحة JPEG عالي الجودة مضمّن في PDF 1.4، فتبقى العربية بتنسيقها كما هي دون خطوط).
- صفحات الصور صارت بنسبة A4 أيضاً (1080×1527). المشاركة عبر الجسر `shareFile` (PDF) مع `ShareProvider`.
- ملاحظة: النص داخل الـPDF صورة (غير قابل للنسخ/البحث).

## 8.36 — ترويسة المؤسسة في PDF، تصدير Excel، وإرسال واتساب تلقائي
- **PDF بترويسة وتذييل المؤسسة** (`www/img/pdf-head.jpg`, `pdf-foot.jpg`) على كل صفحة، مع رقم الصفحة وتاريخ البيانات.
- **Excel (.xlsx)** مولَّد على الجهاز (`www/hr-xlsx.js`: ZIP + XML، أوراق من اليمين لليسار، رأس منسّق ومجمّد): كشف PEF/HHO (ملخص، الحضور، الإجازات، المهام والمغادرات، بلا تسجيل، المتأخرون)، الملخص اليومي (+ حسب السلم)، التقرير الأسبوعي، والمراجعة الشهرية.
- **إرسال PDF تلقائياً إلى واتساب** (`WaAutoService`، خدمة إمكانية وصول): يفتح التطبيق محادثة الرقم والملف مرفق (`jid`) ثم تضغط الخدمة «إرسال» وتعيد التطبيق. أرقام محفوظة قابلة للتعدد والتأشير. تتطلب تفعيلاً يدوياً مرة واحدة من إعدادات «إمكانية الوصول» (وعلى أندرويد 13+ قد تحتاج «السماح بالإعدادات المقيَّدة» للتطبيق المثبّت خارج المتجر)، وتعمل في واتساب فقط وخلال نافذة 60 ثانية يفتحها التطبيق نفسه. غير مجرَّبة على جهاز؛ تعتمد على مُعرِّف زر الإرسال في واجهة واتساب.

## 8.37 — تفريق PEF/HHO بحسب سلم العقد، وExcel أغنى، ومستثنون من الحضور
- **الجهة (PEF/HHO) بحسب «سلم» العقد الحالي:** نص السلم يحوي HHO ← HHO، ويحوي PEF ← PEF (الأحدث الساري)، وإلا تُستنتج من بيانات الموظف كما كان (`orgFromContract`). يسري على الفلاتر والكشوف والصور.
- **المستثنون من تسجيل الحضور:** من في القائمة لا يُحسب غياباً ولا تأخراً في التطبيق والتنبيهات (حالة «مستثنى من الحضور»)، ولا يظهر في صور/ملفات التقارير، وتُسرد أسماؤهم في ورقة «المستثنون» بـExcel.
- **Excel:** الحضور بالاسم والجهة وتاريخ الحضور والدخول والخروج والموقع، والمتأخرون بالتاريخ والوقت والدقائق، وللأسبوعي ورقتا «تفاصيل الحضور» و«كل المتأخرين»، وللمراجعة الشهرية «تفاصيل الأيام».

## 8.38 — حفظ الاستثناءات والإعدادات بعد تسجيل الخروج
- كان تسجيل الخروج أو انتهاء الجلسة يمسح كل بيانات الموارد البشرية بما فيها ما يضعه المستخدم، فتضيع قائمة المستثنين من الحضور. الآن `db.wipe()` يحتفظ بـ: المستثنين (`repExcl`)، المجموعات، قوالب الرسائل، أرقام واتساب، سجل الإنذارات ورسائل SMS وتعديلات الحضور، ربط الموظفين، والإعدادات، ويمسح بيانات النظام المُزامَنة فقط.

## 8.39 — الفرز بين PEF وHHO في قائمة المستثنين
- في «أسماء مستثناة من تسجيل الحضور»: شرائح فرز «الكل / PEF / HHO / المستثنون» بأعدادها، مع البحث بالاسم أو القسم، وزر «استثناء كل الظاهرين» (يتبع الفرز والبحث الحاليين) لاستثناء جهة كاملة أو قسم بنقرة. والأسماء تظهر كاملة بأكثر من سطر بدل الاقتطاع.

## 8.40 — تنسيق Excel احترافي وتعليم المتأخرين بالأحمر
- كل ورقة: عنوان مدمج بخلفية خضراء داكنة، سطر فرعي (التاريخ و«بيانات حتى» ودليل الألوان)، رأس ملوّن، صفوف بحدود ناعمة وتظليل متناوب، توسيط تلقائي للأعمدة القصيرة (أرقام/أوقات/تواريخ)، صف إجمالي، فلتر على الرأس، تجميد الرأس، شبكة مخفية، وإعداد طباعة (A4 أفقي، ملاءمة العرض، تكرار الرأس، ترقيم الصفحات).
- **المتأخرون بالأحمر:** الصف كله بخط أحمر عريض وخلفية وردية في الحضور وكشف المتأخرين وتفاصيل الأسبوع والمراجعة الشهرية (من تأخر ولو مرة).
- (`www/hr-xlsx.js` أنماط وأسماء معرّفة للفلتر والطباعة؛ مفحوص بـopenpyxl وLibreOffice.)

## 8.41 — إرشاد تفعيل الإرسال التلقائي (الإعداد المقيَّد)
- على أندرويد 13+ للتطبيقات المثبّتة خارج المتجر يظهر التطبيق في «إمكانية الوصول» رمادياً بعبارة «يتحكّم فيه إعداد محظور». شاشة الإرسال التلقائي صارت تشرح الخطوات بالترتيب وفيها زران: «١) معلومات التطبيق» (للسماح بالإعدادات المقيَّدة من ⋮) و«٢) إمكانية الوصول» (للتشغيل)، وتتحدّث حالة الخدمة تلقائياً عند العودة للتطبيق مع تأكيد «تم التفعيل».

## 8.42 — بطاقة «اليوم» في ملف الموظف
- أعلى ملف الموظف بطاقة «اليوم»: حالة الدوام (حاضر/متأخر/إجازة/…)، الدخول والخروج وساعات العمل والتأخير، الموقع (اسم موقع العمل وداخل/خارج النطاق والمسافة)، وطلبات اليوم (إجازة/مغادرة/مهمة)، وزر «سجل اليوم بالتفصيل».
- في شريط «الحضور آخر 14 يوماً» تعليم خلية اليوم بإطار ذهبي وعبارة «اليوم».

## 8.43 — تاريخ اليوم بالرقم
- بطاقة «اليوم» تعرض اسم اليوم والتاريخ الرقمي (مثل «الخميس · 19/11/2026»).
- كل خلية في شريط «الحضور آخر 14 يوماً» تحمل اسم اليوم ورقمه، وخلية اليوم بإطار ذهبي وعبارة «اليوم».

## 8.44 — عمود «السلم» (PEF/HHO) في ملفات Excel
- كل صف في أوراق الحضور والمتأخرين والإجازات والمهام وبلا تسجيل والمستثنين (كشف الجهة، الملخص اليومي، الأسبوعي، المراجعة الشهرية) يحمل عمود «السلم» بقيمة PEF أو HHO (بحسب سلم العقد). وفي «بلا تسجيل» بالملخص عمود إضافي «اسم السلم في العقد».

## 8.45 — Excel: السلم والأقسام ونسبة الحضور، وساعات الأسبوعين، وتصميم أرقى
- **ورقة «حسب السلم» بفكرة جديدة:** نوع السلم (PEF/HHO) ثم أقسامه، وصف إجمالي لكل سلم، وإجمالي عام؛ لكل قسم: الموظفون وحاضر ومتأخر وإجازة ومهام وبلا تسجيل و**نسبة الحضور** (تدرّج لوني أحمر←أخضر). أقسام فيها متأخرون بالأحمر.
- **ورقتان جديدتان:** «ساعات الأسبوع الحالي» و«ساعات الأسبوع السابق» (الأحد→السبت): ساعات كل موظف يومياً، أيام الحضور، إجمالي الساعات، الساعات المتوقعة (ساعات الدوام × أيام العمل غير الإجازة)، ونسبة الإنجاز، مع صف إجمالي. في الملخص اليومي (كل الموظفين) وفي كل كشف جهة بحسب جهته.
- **تصميم:** ألوان لسان الأوراق بحسب نوعها، وشارات ملوّنة لـPEF وHHO في أي عمود «السلم»، وصفوف إجمالي فرعي، وتنسيق أرقام (% و0.0)، وتدرّج لوني مشروط، وخصائص المستند (العنوان/المؤلف). (`weekHours`, `sheetsWeekHours`, `bySheet` في hr-report.js؛ أنماط جديدة في hr-xlsx.js).

## 8.46 — Excel: التأخر الشهري برابط تفاصيل، والمسمى الوظيفي، وطلبات اليوم والشهر
- **ورقة «التأخر الشهري»:** عدد مرات التأخر لكل موظف في الشهر الذي تختاره (قائمة «شهر ورقة التأخر الشهري» في شاشة صور الدوام: آخر 6 أشهر، مثل شهر 11 أو 10)، مع إجمالي الدقائق والمتوسط. الصف بأحمر لمن تأخر 3 مرات فأكثر.
- **رابط «عرض التفاصيل»:** رابط داخلي في الملف ينقل مباشرة إلى أول سطر للموظف في ورقة «تفاصيل التأخير» (التاريخ، اليوم، وقت الدخول، دقائق التأخر).
- إن كان في الشهر أيام غير محفوظة تُزامَن تلقائياً قبل التصدير، وإن بقي نقص يظهر تنبيه وملاحظة في الورقة.
- **المسمى الوظيفي** بجانب «القسم» في كل ورقة فيها أسماء موظفين (بما فيها المراجعة الشهرية والمستثنون).
- **«الطلبات اليوم» و«طلبات الشهر»** (من أول الشهر حتى اليوم): المغادرات والإجازات والمهام مع الوقت والساعات والأيام والسبب والحالة، ومرتبة حسب النوع؛ في الملف الموحّد لكل سلم وللملخص.

## 8.47 — Excel: «عرض التفاصيل» ينقل لورقة الموظف المفلترة مع زر رجوع
- الضغط على «عرض التفاصيل» ينقل إلى ورقة خاصة بذلك الموظف فقط (تفاصيل تأخره)، لأن Excel لا يسمح لرابط داخلي بتطبيق فلتر بنفسه.
- في أعلى كل ورقة تفاصيل زر «▸ رجوع إلى التأخر الشهري» يعيدك إلى صف الموظف نفسه في ورقة التأخر الشهري.
- بقيت ورقة «تفاصيل التأخير (كل الموظفين)» مع فلتر الاسم اليدوي وزر رجوع.

## 8.49 — Excel: ورقة تفاصيل تأخير موحّدة بدل أوراق كل موظف
- حُذفت أوراق «ت1، ت2…» لكل موظف. «عرض التفاصيل» ينقل إلى ورقة «تفاصيل التأخير» الموحّدة، لأول سطر في مجموعة الموظف (سطر باسمه وعدد مراته ثم مرات تأخره).

## 8.50 — تصميم جديد للموارد البشرية: فلتر موحّد، مؤشرات، بطاقة موظف، وتصدير موحّد
- **شريط فلتر موحّد** في «اليوم» و«الفريق» و«الحضور»: السلم (الكل/PEF/HHO) + القسم + المسمى الوظيفي + الحالة + ⭐ المحفوظ. الفلاتر تبقى عند التنقل بين الشاشات، ويظهر عدد الفلاتر الفعّالة مع «مسح الكل».
- **فلاتر متقدمة** (ورقة سفلية): اختيار متعدد للأقسام والمسميات وحالة اليوم، وعدّاد «عرض N موظف» مباشر، وحفظ أي تركيبة كـ«فلتر محفوظ» بنقرة لاحقاً.
- **«اليوم»:** نسبة الحضور مع ست بطاقات ملوّنة (حضور، تأخر، بلا تسجيل، إجازة، مهام ومغادرات، طلب معلّق)، كل بطاقة تفتح قائمتها، والأرقام تتبع الفلتر.
- **بطاقة الموظف:** المسمى والقسم وشارة السلم وشريط آخر 14 يوماً بنقاط ملوّنة.
- **تصدير موحّد** في شاشة صور الدوام: صيغة (صورة/PDF/Excel) ← نطاق (المعروض/PEF/HHO/الاثنان) ← أوراق Excel بمربعات اختيار ← إرسال (مشاركة/واتساب تلقائي PDF).

## 8.51 — التحكم في أوراق Excel + إرسال تلقائي يومي والتطبيق مغلق
- **اختيار الأوراق:** في لوحة «التصدير» قائمة بـ12 ورقة (الحضور، المتأخرون، الإجازات، المهام والمغادرات، بلا تسجيل، المستثنون، الملخص، التأخر الشهري وتفاصيله، الطلبات اليوم، طلبات الشهر، ساعات الأسبوعين) بمربعات اختيار وأزرار «الكل / لا شيء»، ويُحفظ اختيارك.
- **إرسال تلقائي يومي:** زر «⏰ إرسال تلقائي يومي لملف Excel» يضبط: وقت الإرسال، أيام الأسبوع، رقم واتساب، محتوى الملف (PEF+HHO / PEF / HHO / الكل)، كشف اليوم أو أمس، مع «جرّب الآن» وعرض آخر تشغيل.
- **التنفيذ:** منبّه دقيق ← مهمة خلفية (`AutoReportJob`) تزامن آخر البيانات وتبني الملف بنفس الأوراق المختارة ← تفتح واتساب على الرقم وتضغط «إرسال» (خدمة الإرسال التلقائي) مع إشعار «تقرير الدوام جاهز» للمشاركة اليدوية. يُعاد ضبط المنبّه بعد إعادة التشغيل والتحديث.
- **المتطلبات:** تفعيل خدمة الإرسال التلقائي (إمكانية الوصول) والسماح بالعرض فوق التطبيقات، وعدم تقييد التطبيق في توفير البطارية.

## 8.52 — عدة أرقام للتقرير اليومي + ضغط «إرسال» أدق
- **أرقام المستلمين:** قائمة أرقام (اسم اختياري) تُضاف وتُحذف من «الإعدادات ← التقرير اليومي التلقائي والأرقام المرسَل إليها» (وأيضاً من لوحة التصدير). يُرسَل الملف إلى كل رقم بالتتابع.
- **ضغط «إرسال»:** بحث شامل في شاشة معاينة واتساب (معرّف الزر أو وصفه «إرسال/Send») مع نقرة احتياطية بالإحداثيات على منتصف الزر إن لم يستجب النقر العادي (تتطلب إعادة تفعيل خدمة الإمكانية بعد التحديث).
- الحالة تُظهر «أُرسل إلى N من M».

## 8.53 — تنبيه إرسال التقرير اليومي (نافذة منبثقة) + تبويب «الإجراءات» حسب سياسة الموارد البشرية
- **تنبيه التقرير اليومي:** عند الموعد (والتطبيق مغلق) يجهّز الملف ثم تظهر **نافذة في منتصف الشاشة** و**إشعار** فيهما «آخر تحديث للبيانات» وزر **إرسال**؛ الضغط عليه يفتح واتساب ويرسل الملف إلى كل الأرقام بالتتابع. الإعدادات: «🔔 نافذة منبثقة وأضغط إرسال (موصى)» أو «⚡ تلقائي كامل». زر «📤 إرسال آخر تقرير جاهز الآن».
- **نص الإرسال:** «مرفق التقرير اليومي» + اليوم والتاريخ والساعة + آخر تحديث للبيانات؛ تكتبه خدمة الإمكانية في خانة الشرح قبل الضغط على «إرسال».
- **تبويب «الإجراءات»** (مبني على «سياسة الموارد البشرية» v3.0): 
  - **حالات الموظفين:** تحليل حضور الشهر لكل موظف مع الإجراء الواجب والجهة والمهلة والمرجع: تأخير ضمن السماح (تنبيه شفهي عند 5، إنذار مكتوب عند 8، خصم من التاسعة)، تأخير بعد 08:15 (خصم كامل المدة)، مغادرة مبكرة (>15 دقيقة مخالفة؛ <15 من الرابعة)، 3 حالات = غياب يوم، ملف انضباطي (3 في الشهر أو 5 في شهرين)، عدم تسجيل خروج (تبرير خلال يومي عمل)، غياب (تبرير يومان ثم غير مبرَّر)، 3 أيام متتالية (لجنة إنهاء خدمة)، دوام في عطلة (تكليف كتابي/يوم بديل)، حدود العمل الإضافي (4 ساعات يومياً و12 أسبوعياً)، الإجازة الطارئة والمرضية. زر «رسالة للموظف» بنص جاهز.
  - **دليل السياسة:** الحضور، الغياب والانقطاع، الإجازات بأنواعها، المهام الميدانية، العمل الإضافي والعطل، الانضباط والاعتراض.

## 8.54 — الخروج من المنصة وحلّ «النظام يقبل جلسة واحدة»
- **زر «الخروج من المنصة»** (قفل مفتوح بجانب المزامنة في أعلى شاشة الموارد البشرية): إمّا **تحرير الحساب مؤقتاً** (30 دقيقة / ساعة / 3 ساعات / حتى الاستئناف) فيُنهي جلسة التطبيق على الخادم دون حذف بياناتك ويوقف الربط في الخلفية، فتدخل النظام من المتصفح بلا رفض «الحساب مستخدم على جهاز آخر»؛ وإمّا **خروج كامل** يحذف بيانات الدخول وبيانات الموارد البشرية من الجوال.
- **تحرير تلقائي** (إعدادات ← الجلسة، مفعّل افتراضياً): يُنهي الجلسة بعد دقيقتين من ترك التطبيق وبعد كل مزامنة خلفية، ما لم تكن «المراقبة الحية للحضور» مفعّلة أو لم تُحفظ بيانات الدخول.
- شريط «تم تحرير الحساب» بزر **استئناف الربط**؛ والمزامنة التي تطلبها بنفسك تستأنف الربط تلقائياً. التقرير اليومي والمزامنة الخلفية لا يعملان أثناء التحرير.

## 8.55 — مركز تصدير Excel اليدوي + تخصيص أوراق الإرسال التلقائي ومعالجته
- **زر «تصدير Excel»** في شاشة اليوم يفتح مركز تصدير: النطاق (PEF+HHO / PEF / HHO / الكل)، تاريخ الكشف (اليوم / أمس / تاريخ محدد)، **أوراق مخصّصة** بمربعات اختيار مع قوالب جاهزة (الكل، الحضور والمتأخرون، الإجازات والمهام، التأخر الشهري، ساعات الأسبوعين، لا شيء)، شهر التأخر، ومزامنة اختيارية قبل التصدير، ثم «تصدير ومشاركة». تُحفظ اختياراتك.
- **الإرسال التلقائي:** صار له اختيار أوراق مستقل (نفس القوالب والمربعات) داخل إعداداته. «جرّب الآن» يبدأ فوراً (لا ينتظر شبكة) ويعرض النتيجة (✓/✗ مع السبب) عند الانتهاء بدل رسالة عامة.
