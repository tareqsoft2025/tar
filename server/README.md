# ملفات السيرفر (tarsof.top)

## `hrnew/mgmt/api.php` — واجهة تطبيق «تنبيهات الإدارة»
1. ارفع الملف إلى `/hrnew/mgmt/api.php` (بجانب `index.php`) دون تعديل أي ملف آخر.
2. يعتمد على ملفات النظام الموجودة (`includes/db.php`, `functions.php`, `auth.php`, `mgmt_ops.php`) وعلى صلاحية `mgmt_ops` (عرض/تعديل).
3. يستعمل جلسة نظام الموارد البشرية نفسها بعد تسجيل الدخول من `login.php`، ويقبل فقط الطلبات التي تحمل الترويسة `X-Requested-With: tarsof-app`.
4. المنطق مطابق لـ `session_save.php` و`directive_save.php` (التحقق، قفل الجلسة، اشتقاق الاسم والمسمّى والراتب من السيرفر، سجل `logAction`).

للتحقق بعد الرفع: افتح التطبيق ← المزيد ← تنبيهات الإدارة ← سجّل الدخول بحساب النظام.
